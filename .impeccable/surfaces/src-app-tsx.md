# Pliflo Main Workspace

Mode: Operate

Audience: people repeatedly preparing and monitoring multi-PDF print batches on macOS.
Job: compose the batch, inspect documents, tune defaults or overrides, then submit and monitor jobs with clear system-state truth.
Constraints: retain all existing functionality, local-only processing, Lucide icons, no emoji, compact desktop utility, no real printing during QA.

## Direction contract

THESIS: Treat a print batch as a mastering console: a precise signal chain from source documents to physical output, refusing the generic three-column admin dashboard feel.
OWN-WORLD: graphite instrument surfaces, paper-white preview, etched rules, compact channel strips, and one restrained phosphor-green state color.
STORY: compose the queue, inspect the active sheet, tune output, then commit the batch while continuously seeing what is ready, submitted, printing, or done.
FIRST VIEWPORT: a narrow document rail at left, dominant paper stage in the center, dense output console at right; a status transport runs across the top and the primary print action anchors the lower-right edge.
FORM: Mastering Console, grounded direction 4, seed 77c669d4.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
